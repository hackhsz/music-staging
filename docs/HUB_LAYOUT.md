# Hub Layout Plan — Stations, NPCs & Size Budget

> **The problem.** The current map is far too large — long empty walks between islands. This doc is the target layout: every station a traditional Roblox social game needs, placed inside a hard size budget so nothing is more than a few seconds away.

## 1. Size budget (hard numbers)

- **Main hub island: `200–240` studs across** (current build is well over this — shrink or pull islands inward).
- **Full loop walk: `20–30` seconds.** Any station reachable from spawn in `≤ 10s`.
- Max `2` satellite islands at launch (Top Players podium islet + Koi Pond floor), each `≤ 5s` bridge walk from the ring. Everything else lives on the main island.
- If we ever keep a bigger map instead: sprint pads / teleport pads become mandatory — but **shrinking is the recommendation**, not speed-ups. Empty transit kills social density.

## 3. Placement logic (the ring)

**One rule above all: from spawn, a new player must SEE the shop, the portals, and the leaderboard without moving.** Sightlines sell the game before any UI does.

Clockwise ring proposal: Spawn plaza (S) → Claim Code + Favorite totem (SW) → Shop + Gacha + Mirror commerce zone (W) → Quest board + NPCs (NW) → **Stage portals (N — hero position, framed by the big tree)** → Leaderboard + podium (NE) → AFK garden + Runway reserve (SE) → back to spawn. Koi Pond floor and podium islet hang off NE/SE edges.

Dance floor/stage is **not** on the hub — portals teleport to the instanced battle stage (existing design), which is what lets the hub shrink.

## 4. What to cut from the current build

- Long lawn stretches between zones — pull all zones onto one ring.
- Duplicate decorative clearings with no station in them.
- Any path longer than ~15 studs without something interactive beside it.
